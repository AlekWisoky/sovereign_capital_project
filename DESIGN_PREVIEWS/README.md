# Design previews

These are **static mockups** (PNG) generated to help you quickly compare UI directions.

Included themes:

1. **cyan_ledger** — Midnight base with neon cyan + violet accents (recommended)
2. **violet_pulse** — Softer purple glow, more “premium finance” vibe
3. **matrix_emerald** — Dark green / emerald (security + ops terminal aesthetic)

Each preview image contains 5 screens:

- Dash
- Tracker
- Ledger
- Agents
- Wallet

In the app, you can switch theme in **Setup**.
