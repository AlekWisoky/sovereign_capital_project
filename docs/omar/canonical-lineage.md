# OMAR canonical learning lineage

Production learning is downstream of the canonical runtime lifecycle:

`decision -> correlation -> execution -> settled outcome -> exact attribution -> policy update`

Capital authority is read from `capital_engine_state()` and is recorded as decision-time context. Operator controls, wealth goals, and AI recommendations are learning context only; governance and execution gates remain authoritative.

OMAR is enabled only with `VICTOR_ENABLE_OMAR=1`.
